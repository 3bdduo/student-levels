# مسابقة ريحانة المدينة — متابعة مستويات الطلاب

## طريقة النشر الكاملة (خطوة بخطوة)

### 1. رفع الملفات على GitHub

1. افتح **GitHub.com** وسجّل دخول
2. اضغط **New Repository**
3. اسم الريبو: مثلاً `rihanat-al-madina`
4. اختار **Public** أو **Private**، ثم اضغط **Create repository**
5. في صفحة الريبو، اضغط **Add file → Upload files**
6. ارفع كل الملفات الموجودة في فولدر `student-levels`:
   - `index.html`
   - `package.json`
   - `manifest.json`
   - `icon-512.png`
   - فولدر `api/` كاملاً (choices.js)
   - فولدر `public/` كاملاً (icon-512.png)
7. اضغط **Commit changes**

---

### 2. نشر الموقع على Vercel

1. افتح **vercel.com** وسجّل دخول بحساب GitHub
2. اضغط **New Project**
3. اختار الريبو اللي رفعته (`rihanat-al-madina`)
4. اضغط **Deploy** مباشرة (مش محتاج تغيّر أي إعداد)
5. بعد الـ Deploy سيظهر لك رابط الموقع

---

### 3. إنشاء قاعدة بيانات Upstash Redis (علشان التغييرات تتحفظ وتبان لكل الأجهزة)

> هذه الخطوة **إلزامية** — بدونها كل معلم يشوف بيانات جهازه فقط ومش بيتشاركوا

1. في Vercel، افتح مشروعك
2. اضغط على تبويب **Storage**
3. اضغط **Create Database**
4. اختار **Upstash Redis**
5. اختار المنطقة الأقرب (مثلاً EU Frankfurt)
6. اضغط **Create and Connect to Project**

✅ **Vercel هيضيف متغيرات البيئة تلقائياً** (`UPSTASH_REDIS_REST_URL` و `UPSTASH_REDIS_REST_TOKEN`) — مش محتاج تكتب أي حاجة بإيدك.

---

### 4. تحديد الكود السري (اختياري)

الكود الافتراضي هو **`123123`**. لو عايز تغيّره:

1. في Vercel → **Settings → Environment Variables**
2. أضف متغير:
   - **Name:** `TEACHER_CODE`
   - **Value:** الكود الجديد اللي تختاره
3. اضغط **Save**

---

### 5. إعادة النشر (Redeploy)

بعد ربط قاعدة البيانات أو تغيير متغيرات البيئة:

1. اذهب لـ **Deployments**
2. اضغط **Redeploy** على آخر نشر

---

## هل التغييرات بتتشارك بين الأجهزة؟

| الحالة | النتيجة |
|--------|---------|
| ✅ بعد ربط Upstash Redis وعمل Redeploy | كل معلم يسجّل طالب يظهر التغيير لكل الأجهزة الأخرى فوراً (كل 10 ثواني auto-refresh) |
| ❌ قبل ربط قاعدة البيانات | كل جهاز يحفظ بيانات محلية فقط ولا تتشارك |
